# 隐私政策

最后更新：2026-09-13

Agent Handoff 是一个用于已有任务或明确接力请求的本地全局 Skill。它不提供远程服务，不包含遥测，不把仓库内容、任务棒、凭据或使用数据发送给发布者。

## 本地访问

明确启用或禁用入口时，Skill 仅修改所选 CLI 用户级规则中的 handoff 标记块。日常接力读写当前仓库的任务数据和 Git 元数据；旧部署清理只处理安装锁证明的协议文件，保留任务历史和业务规则。历史正文仅在用户明确授权的范围内读取。

## 网络与第三方

Skill 自身不发起网络请求。用户从插件市场、GitHub 或其它注册表下载和更新 Skill 时，相应平台会按其自身隐私政策处理账号、下载和安全扫描数据。

## 数据保存

发布者不接收或保存用户数据。全局技能与入口保存在用户本机，任务状态保存在用户自己的仓库和 Git 历史中。

## 联系方式

隐私问题可通过 GitHub Issues 或 `snowsonz@outlook.com` 联系发布者。
