# 任务接力

目标：让新会话直接继续当前工作，并保存可压缩的历史工作记录。规则和模板由全局 Skill 提供，
任务数据放在工作目录的 `.agents/tasks/`，记录不复制规程或固化本机 Skill 路径。
日常接力不依赖 Git，也不配置入口或清理旧部署。

## 文件与读取

- `current.md`：当前任务的目标与完成标准、进展和验证、下一步、有效决策与约束、未决问题。
  接手默认只读它，再核对与下一步有关的实际文件；当前状态应独立支持继续工作。
- `history.md`：当前任务按阶段记录的成果、验证、关键选择及失败教训。查询历史或整理它时读取。
- `archive/<task>/`：已结束任务的 `summary.md`、`history.md`，以及该任务压缩前的原文副本。
  查询已结束任务先读摘要，按用户请求范围读取历史；不扫描全部任务。

历史引用不是必读清单。压缩前原文及旧 Git 版本仅在用户明确要求时读取；摘要有缺口时先核对当前
产物，仍不能确认就说明具体缺口。读取其他会话日志同样需要明确授权，只提取本任务信息。

## 接手与创建

已有 `current.md` 时，结合本轮要求理解目标和下一步，核对必要现场证据后继续。状态与现场冲突时，
修正有证据的内容，未知项明确标记；只读请求只报告，不改文件。只询问确实阻碍下一步的缺失信息。

没有当前记录时，普通工作照常进行。用户要求接手却没有记录时说明缺失，采用本轮已提供的信息；
仍缺少目标才询问。用户明确要求记录延续性工作或保存交接时，使用 `assets/TEMPLATE.md` 创建记录。
若工作已结束，直接保存任务总结，不必先创建活动记录。记录中的推断不能写成已确认事实。

任务标识用日期和简短名称，创建后保持稳定。已有活动任务时继续使用其标识；新任务使用未占用的
标识，不覆盖其他任务的记录。缺少标识的旧记录可在下一次正常更新时补齐。

旧七小节格式按内容直接理解，正常更新时可合并；`owner`、`ack`、`hop` 不再影响接手或需要维护。
旧单文件归档仍可读取，无需批量转换。迁移与安装问题按维护入口处理，不作为记录任务状态的前置条件。

## 更新与交接

有实质进展、重要决策变化、阻塞或准备结束会话时更新记录，无需逐条记工具操作。

1. `current.md` 写最新有效状态：已完成的成果附路径和实际验证结果；未验证的内容明确注明。
   下一步写清要做什么及怎样判断完成，第一项不依赖历史链接。保留影响后续的决策理由、约束和阻塞。
2. 本阶段值得保留的变化追加到 `history.md`，标注日期：成果与验证、选择及理由、失败尝试及教训。
   不重复追加同一成果；被替代的判断留在历史并注明替代原因，当前记录只保留有效结论。
3. 核对当前记录与历史没有把未完成写成完成、遗漏待办或矛盾的有效约束。更新 `updated`。
   先保存历史再精简当前记录；中断后核对已保存内容再继续，避免重复或丢失。

当前记录保持简短；把已不影响下一步的过程移入历史，接手必需的信息仍留在当前记录。
空小节可省略，约束与禁区合并表达。文件保存即完成交接；提交、分支和合并沿用项目规则。

## 压缩历史

`history.md` 超过约 **6,000 个 Unicode 字符**或用户要求时，按阶段整理摘要；短小清晰的记录不改。
阈值是整理提示，不是删信息的硬限额。当前必要状态不能为了长度而删除。

1. 用本轮已读取的历史生成摘要，保留成果和产物路径、验证结果、关键决策及理由、失败教训和遗留事项。
   合并重复过程，明确哪些判断已失效以及原因；不把后来认识写成当时事实。
2. 替换前，将本轮输入的历史原文保存到 `archive/<task>/history-<唯一时间戳>.md`，确认副本与输入
   一致。已有同名文件时另选名称，不能覆盖。副本写入或核对失败时保留原历史，不进行替换。
3. 核对摘要未丢失上述信息，附原文副本的路径（以 `.agents/tasks/` 为基准，归档后不变），
   再替换 `history.md`。若源文件期间已变化，
   重新读取当前源文件并合并后再处理，不覆盖新内容。无需提交、读取 Git 旧版本或检查提交基线。

后续压缩只使用当前历史摘要和新增记录，保留已有来源引用，不递归加载原文副本。
副本核对是对本轮输入的保存验证，不是重新读取已压缩历史。中断留下的副本可以保留，不据此删除源文件。

## 完成与归档

达到目标和完成标准，且无未完成工作或阻塞时，将最终成果、验证、关键决策和非阻塞遗留写入
`archive/<task>/summary.md`，历史整理后保存为同目录的 `history.md`。原文来源应仍能从归档定位。

先保存并核对归档，再移除该任务的 `current.md` 和活动 `history.md`。已有摘要或历史目标文件时先
核对是否为本次中断留下的相同内容；不一致则保留双方并报告冲突，不能覆盖或清除活动记录。
归档目录内仅有本任务压缩副本是正常情况。未达成目标的暂停仍保留当前记录及下一步。
